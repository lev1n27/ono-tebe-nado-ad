# Оно тебе надо

Проектная работа Яндекс Практикума: лендинг аукциона вещей, в которые никто не верил.

## Что на странице

- Шапка с меню, логотипом и контактами.
- Обложка с крупным заголовком и кнопкой «Сделать ставку».
- Секция с карточками лотов.
- Секция «Об аукционе».
- Подвал с контактами, меню и ссылками на соцсети.

## Технологии

- Семантическая разметка HTML5: `header`, `main`, `section`, `article`, `nav`, `address`, `footer`.
- CSS Grid для шапки, секции «Об аукционе» и подвала.
- Flexbox для меню, карточек и обложки.
- Позиционирование для полупрозрачного оверлея на обложке и карточках.
- Локальные шрифты Raleway в форматах `woff2` и `woff`.

## Как открыть

Откройте файл `index.html` в браузере. Макет рассчитан на ширину экрана 1100px.
